## ⭐ Featured Projects

### [YOLOv8 Human Pose Estimation: Improved Prediction & Surveillance](https://github.com/neiorz/ComputerVision_FP)
Improves the predictions of the pre-trained YOLOv8 pose model by reducing false positives, filling missing detections across consecutive frames, and stabilizing detections in dynamic environments.

- Security surveillance pipeline combining real-time **pose estimation** with **staff authorization** through ID-card segmentation
- Tracks people and classifies behavior (static, walking, running)
- Automated evaluation across confidence thresholds, logging Precision, Recall, mAP, and F1 to find the best setting
- Works with webcam, video, images, and Kinect camera input

**Stack:** Python, Ultralytics YOLOv8, OpenCV, NumPy, Jupyter

### [YaqzBot: AI & ROS 2 Vision Module (Graduation Project)](https://github.com/neiorz/Graduation-Project)
The AI and vision subsystem of an autonomous robot, bridging real-time perception with robotic control.

- **YOLOv8** object detection integrated with **ROS 2 Jazzy**
- High-performance C++ integration package with lifecycle-managed nodes for low-latency inference
- Models optimized to **ONNX** for stable real-time deployment on Linux robotic platforms
- Clean separation between AI research code and ROS 2 production code

**Stack:** Python, C++, YOLOv8, ONNX, ROS 2 Jazzy, OpenCV, Git LFS
